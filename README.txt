ПОРТРЕТ ЛИЧНОСТИ
================
Модуль психологического тестирования. Пользователь отвечает на вопросы
нескольких методик, система считает баллы по ключам, определяет уровень по
каждой шкале и собирает общий отчёт «Портрет личности» (на сайте и в JSON).

Учебная практика УП.01.01. Стек: Python 3.10+, FastAPI, HTML/JS.


ВОЗМОЖНОСТИ
-----------
- Ядро: движок опроса (вопросы по одному, прогресс, возврат назад) и сборщик
  результатов. Ядро не знает, какие именно тесты подключены.
- Методики подключаются отдельными модулями по единому контракту.
- Подсчёт по ключам: прямые и обратные вопросы, несколько шкал в одной методике,
  уровни (низкий / средний / высокий) и текстовая интерпретация.
- Проверка достоверности: предупреждения, если все ответы одинаковые или ответы
  на прямые и обратные вопросы противоречат друг другу.
- Устойчивость к сбоям: если одна методика не посчиталась, остальные всё равно
  попадут в портрет.
- Валидатор: сверяет каждый вопрос с эталонными ключами и делает контрольные
  прогоны (все ответы минимальные / максимальные).
- Веб-интерфейс (прогресс-бар, экран результатов) и REST API (документация /docs).
- Консольный режим и автотесты.


ПОДКЛЮЧЁННЫЕ МЕТОДИКИ (3 из 20)
-------------------------------
1. Шкала самооценки Розенберга         — 10 вопросов, 1 шкала
2. Большая пятёрка (IPIP-50)           — 50 вопросов, 5 шкал
3. Шкала воспринимаемого стресса PSS-10 — 10 вопросов, 1 шкала
Всего 70 вопросов. Остальные методики добавляются по тому же образцу.


БЫСТРЫЙ ЗАПУСК
--------------
1) Установите Python 3.10 или новее.
2) В папке проекта выполните:
       pip install -r requirements.txt
       uvicorn portrait.api:app --reload
3) Откройте в браузере http://127.0.0.1:8000
   Документация API: http://127.0.0.1:8000/docs

Подробная пошаговая инструкция: ИНСТРУКЦИЯ_ПО_ЗАПУСКУ.txt


КОМАНДЫ
-------
  uvicorn portrait.api:app --reload             запуск сайта
  python -m portrait run                        опрос в консоли
  python -m portrait demo                       демо-отчёт без ввода ответов
  python -m portrait validate                   валидатор (сверка ключей)
  python -m unittest discover -s tests -t .     автотесты


API
---
  GET  /                              страница опроса
  GET  /api/methods                   список методик
  GET  /api/methods/{id}/questions    вопросы и варианты ответа (без ключей подсчёта)
  POST /api/portrait                  ответы → «Портрет личности» (JSON)
  GET  /api/validate                  результат валидатора

Пример запроса POST /api/portrait:
  {"answers": {"rosenberg": {"ros_1": 3, "ros_2": 2}}}


СТРУКТУРА ПРОЕКТА
-----------------
  portrait/models.py          контракты данных (вопрос, шкала, методика)
  portrait/engine.py          движок опроса
  portrait/scoring.py         подсчёт баллов и проверка достоверности
  portrait/collector.py       сборщик «Портрета личности»
  portrait/methods/           методики (rosenberg, bigfive, pss10) и реестр
  portrait/reference_keys.py  эталонные ключи для сверки
  portrait/validator.py       валидатор
  portrait/service.py         логика API без привязки к фреймворку
  portrait/api.py             FastAPI-приложение
  portrait/static/index.html  веб-страница
  portrait/cli.py             консольный интерфейс
  tests/                      автотесты
  requirements.txt            зависимости

Подробное описание логики: ЛОГИКА_И_ПРОЕКТ.txt


КАК ДОБАВИТЬ НОВУЮ МЕТОДИКУ
---------------------------
1) Создать portrait/methods/<имя>.py со SPEC = MethodSpec(...): вопросы,
   варианты ответа, ключи, шкалы, диапазоны и тексты интерпретации.
2) Добавить SPEC в REGISTRY в portrait/methods/__init__.py.
3) Добавить эталонные ключи в portrait/reference_keys.py.
4) Запустить валидатор и автотесты.


ОГРАНИЧЕНИЯ
-----------
- Тексты интерпретации учебные и ориентировочные. Это не клиническая диагностика.
- Формулировки вопросов — рабочий перевод; при необходимости сверьте с
  официальной русской версией методики.
- Ответы хранятся в памяти браузера: при обновлении страницы опрос
  начинается заново.
